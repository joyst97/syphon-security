Privacy Policy

Last Updated: August 4, 2026

1. Data We Collect

JOYST CORPORATION SECURITY BOT collects only essential data strictly necessary for security moderation and server protection:

  • Guild (Server) IDs and Security Configuration Settings
  • User IDs for warning threshold tracking, tempban countdowns, and whitelist entries
  • Security Audit Incident Logs (Action records taken by moderators or automated filters)

2. Data Storage & Security

All data is stored securely in an encrypted local database. Tempban countdown records are automatically deleted upon expiration. No personal user data or message content is stored permanently.

3. Third-Party Data Sharing

We do NOT share, sell, trade, or transfer collected Discord server data with third-party organizations or advertisers.

4. User Data Removal

Server owners may request immediate removal of their server's security settings or database logs at any time by contacting support.
